# Johan Lourens — Portfolio

Personal portfolio site built with plain HTML, CSS, and JavaScript — no framework, no build step.

Live at: https://0xjl.github.io/

## Structure

- `index.html` — page content
- `css/style.css` — styles
- `js/script.js` — scroll reveals, nav, card interactions

## Run locally

```bash
npx serve .
```
